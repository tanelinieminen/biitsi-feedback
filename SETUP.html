🌴 Palautelomake & Dashboard

Vaihe-vaiheelta ohje palautelomakkeen asentamiseen ja käyttöönottoon GitHubissa.

📋 Yleiskatsaus

Biitsi palautelomakejärjestelmä koostuu kahdesta päätiedostosta:

📝

Palautelomake

feedback.html
Asiakkaiden täyttämä lomake

📊

Dashboard

dashboard.html
Vastausten analysointi & hallinta

ℹ️ Järjestelmä toimii kokonaan selaimessa (localhost) käyttäen localStorage-teknologiaa. Ei palvelintaustan tarvetta.

📁 Tiedostorakenne

GitHubissa järjestys olisi seuraava:

feedback/
├── index.html
├── dashboard.html
├── SETUP.html
└── README.md

Tiedostojen merkitys:

  • feedback.html – Palautelomake, avaa osoitteesta /feedback/
  • dashboard.html – Hallintapaneeli, avaa osoitteesta /feedback/dashboard.html
  • SETUP.html – Tämä opas
  • README.md – GitHub-dokumentaatio

🚀 Käyttöönotto

1

Lataa tiedostot GitHubista

Kloonaa repon feedback-kansio:

git clone <repo-url>
cd feedback
2

Testaa paikallisesti

Avaa tiedostot suoraan selaimessasi tai käytä yksinkertaista palvelinta:

# Python 3
python -m http.server 8000

# tai Node.js http-server
npx http-server

Siirry osoitteeseen http://localhost:8000/feedback/

3

Deployaa web-palvelimelle

Paina muutokset GitHubiin ja deployaa palvelimellesi (esim. GitHub Pages, Vercel, Netlify):

git add .
git commit -m "Päivitys: uusi palautelomake"
git push origin main

📝 Palautelomakkeen käyttö

Ominaisuudet

  • Kaksikielinen – Suomi & Englanti
  • Nimi ja yritys – Erilliset kentät
  • NPS 0-10 – Suositteluindeksi nyt 0-10 asteikolla
  • Klikkaa poistamaan – Voit poistaa valitun vastauksen klikkaamalla sitä uudelleen
  • 12 arviointialuetta – Tunnelma, musiikki, tilat, jne.
  • Avoin palaute – Vapaa kommenttikenttä
  • Urheilijatuen valinta – Maajoukkueen tukeminen

Datan tallennus

Kun asiakkaiden täyttävät lomakkeen:

  1. Data tallennetaan selaimen localStorage-muistiin
  2. Data on näkyvillä dashboard.html:ssä kirjautumisen jälkeen
  3. Voit viedä datan CSV-muodossa hallintapaneelista
💡 Vihje: Kunkin lomakkeen täytön jälkeen näkyy "Iso kiitos palautteestanne!" -viesti ja data tallennetaan automaattisesti.

📊 Hallintapaneelin (Dashboard) käyttö

Kirjautuminen

Dashboard on suojattu salasanalla:

Oletussalasana: biitsi2024
⚠️ Turvallisuus: Muuta salasana ennen julkaisua! Avaa dashboard.html, etsi const DEFAULT_PASSWORD ja muuta arvo.

Näkymät

  • Yhteenveto – Vastausmäärä, NPS-pisteet, keskiarvo
  • Kaaviot – NPS-jakauma, odotuksiin vastaaminen, lähde
  • Yksittäiset vastaukset – Hae ja suodata vastauksia
  • Poista vastaukset – Jokaisen vastauksen kohdalla roskakori-nappi

Toiminnot

  • Vie CSV – Vie vastaukset Excel-taulukkoon
  • Tuo CSV – Tuo aiempia vastauksia CSV-tiedostosta
  • Poista-nappi – Poista yksittäisiä vastauksia
  • Suodattimet – Hae nimen, yrityksen tai palautteen perusteella
💡 Vihje: Data säilyy selaimessa. Vie CSV-muodossa säilyttämistä varten!

⚙️ Konfiguraatio

Salasanan vaihto

Avaa dashboard.html tekstieditorilla ja etsi rivi:

const DEFAULT_PASSWORD = 'biitsi2024';

Vaihda biitsi2024 omaksesi, esim:

const DEFAULT_PASSWORD = 'ominensalasana123';

Brändäys

CSS-värit voi muuttaa molemmissa tiedostoissa. Etsi :root sektiosta:

--lime: #FBFFA8; /* Biitsin keltainen */
--black: #111111; /* Pääväri */
--cream: #FEFFEE; /* Tausta */

Teksti & kielet

Molemmat tiedostot käyttävät data-fi ja data-en attribuutteja kaksikielisyydelle. Muuta tekstit etsiessä näitä attribuutteja.

🔧 Ongelmanratkaisu

Data ei näy dashboardissa

  • Tarkista, että käytät samaa verkkotunnusta (localhost tai sama domain)
  • Avaa selaimen Developer Tools (F12) → Application → localStorage
  • Etsi avain biitsi_responses

Salasana ei toimi

  • Tyhjennä selaimen välimuisti (Ctrl+Shift+Del)
  • Tarkista, että muutit salasanan dashboard.html oikealla tavalla
  • Kirjaudu ulos ja yritä uudelleen

CSV-viennin toiminnot

  • Vie-nappi lataa tiedoston biitsi-palautteet-YYYY-MM-DD.csv
  • Tuonnin yhteydessä nykyiset tiedot ylikirjoitetaan
